# Registro de hipóteses da auditoria do Fundo Missionário

Catálogo das hipóteses **sem prova documental**. Regras deste registro:

- Uma hipótese registrada **não cria ajuste, não altera saldo, não reclassifica lançamento e não gera compensação**.
- Cada hipótese tem **estado**, **grau de confiança**, **justificativa** e o **documento que a fecha**.
- Só a chegada do documento muda o estado. Se o documento mostrar outra natureza, a regra de governança manda
  **reclassificar** (não ajustar). Ajuste só com prova documental.
