3 · A tela inteira: de "linhas do banco" para "contas a pagar"

Visão por obrigação como padrão. À esquerda, o que a Tesouraria espera; à direita, o que o banco mostrou. A fila de exceção (o que sobra) é onde se cria despesa nova.
